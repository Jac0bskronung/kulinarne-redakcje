**Nowy Google Search Box: Rewolucja po 25 latach** — Google zaprezentowało odświeżony wygląd pola wyszukiwania, pierwszy raz od ćwierćwieku. Zmiany te mają znaczenie wykraczające poza estetykę, sugerując głębsze integracje z technologiami AI. [VentureBeat AI]

**Claude Fable 5: Proaktywność na nowym poziomie** — Anthropic wypuściło nową wersję swojego modelu Claude Fable 5, która wyróżnia się niezwykłą proaktywnością. **Open-source GLM-5.2: Potężny LLM tekstowy** — Chińskie laboratorium AI Z.ai udostępniło GLM-5.2, które jest prawdopodobnie najpotężniejszym otwartym modelem językowym skupionym wyłącznie na tekście. Model ten oferuje imponujące możliwości przetwarzania i generowania treści tekstowych. [Simon Willison]

**Claude Code kontra Goose: Kosztowne AI dla programistów** — Podczas gdy Claude Code od Anthropic oferuje zaawansowane możliwości dla programistów, jego wysokie koszty (do 200 USD miesięcznie) stają się barierą. ## 🚀 Projekty GitHub warte uwagi

**[ponytail](https://github.com/DietrichGebert/ponytail)** (JavaScript, 73238★) — Ten projekt pozwala na tworzenie agentów AI, którzy myślą jak najbardziej leniwi starsi programiści. Ideą jest minimalizowanie ilości pisania kodu, co może przyspieszyć rozwój i zmniejszyć liczbę błędów. Warto obserwować jego rozwój pod kątem innowacyjnych podejść do automatyzacji kodowania.

**[omnigent](https://github.com/omnigent-ai/omnigent)** (Python, 6179★) — Omnigent to otwarty framework dla agentów AI, który umożliwia orkiestrację różnych modeli, takich jak Claude Code, Codex czy Pi. Jego zaletą jest łatwość wymiany "harnessów" bez potrzeby przepisywania kodu oraz możliwość egzekwowania polityk i sandboxing. Jest to obiecująca platforma do budowania złożonych systemów AI.

**[Datasette Apps](https://github.com/datasette/datasette-apps)** (Python, brak gwiazdek, ale nowość) — Nowy plugin do Datasette, który pozwala na hostowanie niestandardowych aplikacji HTML bezpośrednio wewnątrz platformy. Otwiera to drogę do tworzenia i wdrażania prostych, ale funkcjonalnych aplikacji webowych w lekkim środowisku, co jest interesujące dla deweloperów chcących szybko prototypować.
